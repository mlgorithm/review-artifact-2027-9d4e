# Anonymous review materials

This repository contains supplementary material, experiment code, and aggregate result tables for *Synthetic Data for Whom? Evaluating Synthetic Data for Uncommon Learning Pathways*. The main manuscript and its source files are not included. No student-level records or generated learner trajectories are included.

- [Supplementary material (PDF)](https://anonymous.4open.science/r/artifact-8f39c2/supplementary.pdf) is the authoritative, paginated supplement, including the supporting disclosure-audit figure.
- [Supplementary material (Markdown)](https://anonymous.4open.science/r/artifact-8f39c2/supplementary.md) provides searchable text and the complete numerical tables. The Markdown version was converted from the supplement source; consult the PDF for final figure layout and reference formatting.
- [Supplement-generated](https://anonymous.4open.science/r/artifact-8f39c2/supplement-generated/) contains aggregate result tables, applicability and status records, and the CSVs behind the supplement. Missing or unsupported comparisons are documented rather than represented as zero.
- [Tables](https://anonymous.4open.science/r/artifact-8f39c2/tables/) contains the additional aggregate CSV tables and table definitions.
- [Code](https://anonymous.4open.science/r/artifact-8f39c2/code/) contains the generation and evaluation pipeline, dataset-preparation scripts, configurations, tests, and curated JSON report snapshots. Start with the [code guide](https://anonymous.4open.science/r/artifact-8f39c2/code/README.md) and [experiment guide](https://anonymous.4open.science/r/artifact-8f39c2/code/experiments/README.md) for dependencies and reproduction commands.

Raw datasets must be obtained separately from their original sources.
